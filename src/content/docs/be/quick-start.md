# Junco

## Файлы, якія падтрымліваюцца

Зараз падтрымліваюцца JSON і YAML.

## Адкрыццё і захаванне файлаў

Адкрыйце файл праз **Файл → Адкрыць файл**. Пасля змен захавайце яго праз
**Файл → Захаваць файл** або спалучэннем клавіш `Ctrl+S`.

Новы файл можна стварыць праз **Файл → Стварыць**.

## Схемы файлаў

Для працы з файлам Junco патрэбна схема. Яна вызначае тыпы палёў і ўласцівасці,
якія паказваюцца ў рэдактары.

Можна паспрабаваць стварыць схему аўтаматычна: у паведамленні пра адсутную схему
націсніце **Стварыць схему**. Праверце створаную схему і пры неабходнасці
адрэдагуйце яе ўручную.

Схема захоўваецца побач з файлам пад імем **`імя_файла`.schema.json**.

## Абмежаванні

Каранёвым тыпам файла павінен быць аб'ект: гэта неабходна для захавання
метададзеных у полі **`__meta__`**.

## Рэдагаванне схемы

Каб пераключыцца паміж рэдагаваннем файла і схемы, націсніце **Рэдагаваць схему**
ўверсе асноўнай панэлі. Рэдагаванне схемы таксама даступна праз меню
**Праўка → Схема → Рэдагаваць схему**.

Схема адпавядае JSON Schema, але падтрымліваюцца не ўсе магчымасці стандарту.

## Інтэрфейс

У праграме тры панэлі:

- **Дрэва** — дрэва палёў для хуткай навігацыі па файле.
- **Асноўная панэль** — тут рэдагуецца змест файла або яго схема.
- **Панэль валідацыі** — тут паказваюцца памылкі праверкі.
