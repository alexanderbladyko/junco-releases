# Палі

Junco падтрымлівае наступныя тыпы палёў.

## Базавыя палі

### Boolean

Значэнне «так» або «не», якое ў рэдактары паказваецца як пераключальнік.
Выкарыстоўвайце яго для налад, якія можна ўключыць або выключыць.

### String

Адвольны тэкст: імёны, подпісы, URL і іншыя тэкставыя значэнні.

| Поле         | Тып     | Апісанне                                         |
| ------------ | ------- | ------------------------------------------------ |
| `Min length` | integer | Найменшая колькасць сімвалаў у значэнні.         |
| `Max length` | integer | Найбольшая колькасць сімвалаў у значэнні.        |
| `Pattern`    | string  | Рэгулярны выраз, якому павінен адпавядаць тэкст. |

### Integer

Цэлы лік без дробнай часткі. Падыходзіць для колькасці, пазіцый і іншых
значэнняў без дзесятковых знакаў.

| Поле         | Тып     | Апісанне                          |
| ------------ | ------- | --------------------------------- |
| `Min length` | integer | Найменшае дапушчальнае значэнне.  |
| `Max length` | integer | Найбольшае дапушчальнае значэнне. |

### Number

Лік, які можа мець дробную частку. Выкарыстоўвайце яго для вымярэнняў, цэн,
працэнтаў і падобных значэнняў.

| Поле         | Тып     | Апісанне                          |
| ------------ | ------- | --------------------------------- |
| `Min length` | integer | Найменшае дапушчальнае значэнне.  |
| `Max length` | integer | Найбольшае дапушчальнае значэнне. |

### Enum

Значэнне з загадзя вызначанага спісу. Выкарыстоўвайце enum, калі трэба выбіраць
вядомы варыянт, а не ўводзіць адвольны тэкст.

| Поле      | Тып              | Апісанне                                    |
| --------- | ---------------- | ------------------------------------------- |
| `Options` | array of strings | Значэнні, даступныя для выбару ў рэдактары. |

### File

Спасылка на файл. Выкарыстоўвайце гэта поле, калі значэнне павінна ўказваць на
файл, які выбіраецца ў файлавай сістэме.

### Image

Спасылка на файл выявы. Падыходзіць для палёў, што захоўваюць шлях да выявы і
паказваюць у рэдактары элементы кіравання выявай.

## Складаныя палі

### Object

Аб'ект аб'ядноўвае фіксаваны набор названых уласцівасцей у адно значэнне. У
кожнай уласцівасці ёсць уласная схема, таму аб'ект зручны для звязаных налад —
напрыклад, злучэння з серверам або профілю карыстальніка. Выкарыстоўвайце яго,
калі структура даных вядомая загадзя; калі колькасць запісаў змяняецца, выберыце
масіў.

| Поле            | Тып    | Апісанне                                                                                                                         |
| --------------- | ------ | -------------------------------------------------------------------------------------------------------------------------------- |
| `Display field` | string | Назва ўласцівасці, якая будзе подпісам аб'екта ў рэдактары. Выберыце кароткае зразумелае значэнне, напрыклад `name` або `title`. |

### Array

Упарадкаваны спіс значэнняў. Для кожнага запісу прымяняецца адна і тая ж схема,
таму масівы зручныя для тэгаў, задач, карыстальнікаў і іншых паўтаральных даных.
Элементамі могуць быць базавыя значэнні або аб'екты; мінімальная і максімальная
колькасць абмяжоўвае лік запісаў, якія можна дадаць.

| Поле        | Тып     | Апісанне                                   |
| ----------- | ------- | ------------------------------------------ |
| `Min items` | integer | Мінімальная колькасць элементаў у масіве.  |
| `Max items` | integer | Максімальная колькасць элементаў у масіве. |

## Any Of

Выкарыстоўвайце `anyOf`, калі поле можа мець адну з некалькіх дапушчальных
структур. Кожны варыянт — поўная схема поля, а значэнне павінна адпавядаць
хаця б адной з іх. Напрыклад, кантакт можа быць радком з адрасам электроннай
пошты або аб'ектам з данымі тэлефона. Рабіце варыянты выразна рознымі і давайце
ім зразумелыя назвы, каб было ясна, што выбіраць.
