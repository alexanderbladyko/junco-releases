# Junco

## Підтримувані файли

Наразі підтримуються JSON і YAML.

## Відкривання та збереження файлів

Відкрийте файл через **Файл → Відкрити файл**. Після змін збережіть його через
**Файл → Зберегти файл** або комбінацією клавіш `Ctrl+S`.

Новий файл можна створити через **Файл → Створити**.

## Схеми файлів

Для роботи з файлом Junco потрібна схема. Вона визначає типи полів і властивості,
що відображаються в редакторі.

Можна спробувати створити схему автоматично: у повідомленні про відсутню схему
натисніть **Створити схему**. Перевірте створену схему й за потреби відредагуйте
її вручну.

Схема зберігається поруч із файлом під назвою **`ім'я_файлу`.schema.json**.

## Обмеження

Кореневим типом файлу має бути об'єкт: це потрібно для зберігання метаданих у
полі **`__meta__`**.

## Редагування схеми

Щоб перемкнутися між редагуванням файлу й схеми, натисніть **Редагувати схему**
вгорі основної панелі. Редагування схеми також доступне в меню
**Редагування → Схема → Редагувати схему**.

Схема відповідає JSON Schema, але підтримуються не всі можливості стандарту.

## Інтерфейс

У застосунку є три панелі:

- **Дерево** — дерево полів для швидкої навігації файлом.
- **Основна панель** — тут редагується вміст файлу або його схема.
- **Панель валідації** — тут відображаються помилки перевірки.
