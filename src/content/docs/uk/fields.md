# Поля

Junco підтримує такі типи полів.

## Базові поля

### Boolean

Значення «так» або «ні», що в редакторі відображається як перемикач.
Використовуйте його для налаштувань, які можна ввімкнути або вимкнути.

### String

Довільний текст: імена, підписи, URL та інші текстові значення.

| Поле         | Тип     | Опис                                           |
| ------------ | ------- | ---------------------------------------------- |
| `Min length` | integer | Найменша кількість символів у значенні.        |
| `Max length` | integer | Найбільша кількість символів у значенні.       |
| `Pattern`    | string  | Регулярний вираз, якому має відповідати текст. |

### Integer

Ціле число без дробової частини. Підходить для кількостей, позицій та інших
значень без десяткових знаків.

| Поле         | Тип     | Опис                          |
| ------------ | ------- | ----------------------------- |
| `Min length` | integer | Найменше допустиме значення.  |
| `Max length` | integer | Найбільше допустиме значення. |

### Number

Число, яке може мати дробову частину. Використовуйте його для вимірювань, цін,
відсотків та подібних значень.

| Поле         | Тип     | Опис                          |
| ------------ | ------- | ----------------------------- |
| `Min length` | integer | Найменше допустиме значення.  |
| `Max length` | integer | Найбільше допустиме значення. |

### Enum

Значення з наперед визначеного списку. Використовуйте enum, коли потрібно
вибрати відомий варіант, а не вводити довільний текст.

| Поле      | Тип              | Опис                                       |
| --------- | ---------------- | ------------------------------------------ |
| `Options` | array of strings | Значення, доступні для вибору в редакторі. |

### File

Посилання на файл. Використовуйте це поле, коли значення має вказувати на файл,
який вибирається у файловій системі.

### Image

Посилання на файл зображення. Підходить для полів, що зберігають шлях до
зображення та показують у редакторі елементи керування зображенням.

## Складні поля

### Object

Об'єкт об'єднує фіксований набір іменованих властивостей в одне значення. Кожна
властивість має власну схему, тому об'єкт зручний для пов'язаних налаштувань —
наприклад, з'єднання із сервером або профілю користувача. Використовуйте його,
коли структура даних відома заздалегідь; якщо кількість записів змінюється,
оберіть масив.

| Поле            | Тип    | Опис                                                                                                                         |
| --------------- | ------ | ---------------------------------------------------------------------------------------------------------------------------- |
| `Display field` | string | Назва властивості, яка буде підписом об'єкта в редакторі. Виберіть коротке зрозуміле значення, наприклад `name` або `title`. |

### Array

Впорядкований список значень. До кожного запису застосовується одна й та сама
схема, тому масиви зручні для тегів, завдань, користувачів та інших повторюваних
даних. Елементами можуть бути базові значення або об'єкти; мінімальна й
максимальна кількість обмежує число записів, які можна додати.

| Поле        | Тип     | Опис                                      |
| ----------- | ------- | ----------------------------------------- |
| `Min items` | integer | Мінімальна кількість елементів у масиві.  |
| `Max items` | integer | Максимальна кількість елементів у масиві. |

## Any Of

Використовуйте `anyOf`, коли поле може мати одну з кількох допустимих структур.
Кожен варіант — повна схема поля, а значення має відповідати хоча б одному з
них. Наприклад, контакт може бути рядком з адресою електронної пошти або
об'єктом із даними телефону. Робіть варіанти чітко різними та давайте їм
зрозумілі назви, щоб було ясно, що обирати.
