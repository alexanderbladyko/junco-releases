# Поля

Junco поддерживает следующие типы полей.

## Базовые поля

### Boolean

Значение «да» или «нет», которое в редакторе отображается как переключатель.
Используйте его для настроек, которые можно включить или выключить.

### String

Произвольный текст: имена, подписи, URL и другие текстовые значения.

| Поле         | Тип     | Описание                                                     |
| ------------ | ------- | ------------------------------------------------------------ |
| `Min length` | integer | Минимальное количество символов в значении.                  |
| `Max length` | integer | Максимальное количество символов в значении.                 |
| `Pattern`    | string  | Регулярное выражение, которому должен соответствовать текст. |

### Integer

Целое число без дробной части. Подходит для количества, позиций и других
значений без десятичных знаков.

| Поле         | Тип     | Описание                        |
| ------------ | ------- | ------------------------------- |
| `Min length` | integer | Наименьшее допустимое значение. |
| `Max length` | integer | Наибольшее допустимое значение. |

### Number

Число, которое может содержать дробную часть. Используйте его для измерений,
цен, процентов и похожих значений.

| Поле         | Тип     | Описание                        |
| ------------ | ------- | ------------------------------- |
| `Min length` | integer | Наименьшее допустимое значение. |
| `Max length` | integer | Наибольшее допустимое значение. |

### Enum

Значение из заранее заданного списка. Используйте enum, когда нужно выбрать
из известных вариантов, а не вводить произвольный текст.

| Поле      | Тип              | Описание                                    |
| --------- | ---------------- | ------------------------------------------- |
| `Options` | array of strings | Значения, доступные для выбора в редакторе. |

### File

Ссылка на файл. Используйте это поле, когда значение должно указывать на файл,
выбираемый из файловой системы.

### Image

Ссылка на файл изображения. Подходит для полей, которые хранят путь к картинке
и показывают в редакторе элементы управления изображением.

## Сложные поля

### Object

Объект объединяет фиксированный набор именованных свойств в одно значение.
У каждого свойства есть собственная схема, поэтому объект удобен для связанных
настроек — например, подключения к серверу или профиля пользователя. Используйте
его, когда структура данных известна заранее; если число записей меняется,
выберите массив.

| Поле            | Тип    | Описание                                                                                                                    |
| --------------- | ------ | --------------------------------------------------------------------------------------------------------------------------- |
| `Display field` | string | Имя свойства, которое будет подписью объекта в редакторе. Выберите короткое понятное значение, например `name` или `title`. |

### Array

Упорядоченный список значений. Для каждой записи применяется одна и та же схема,
поэтому массивы удобны для тегов, задач, пользователей и других повторяющихся
данных. Элементами могут быть базовые значения или объекты; минимальное и
максимальное количество ограничивает число добавляемых записей.

| Поле        | Тип     | Описание                                     |
| ----------- | ------- | -------------------------------------------- |
| `Min items` | integer | Минимальное количество элементов в массиве.  |
| `Max items` | integer | Максимальное количество элементов в массиве. |

## Any Of

Используйте `anyOf`, когда поле может иметь одну из нескольких допустимых
структур. Каждый вариант — полноценная схема поля, а значение должно
соответствовать хотя бы одной из них. Например, контакт может быть строкой с
адресом электронной почты или объектом с данными телефона. Делайте варианты
отчётливо разными и давайте им понятные названия, чтобы было ясно, что выбирать.
