# Junco

## Поддерживаемые файлы

Сейчас поддерживаются JSON и YAML.

## Открытие и сохранение файлов

Откройте файл через **Файл → Открыть файл**. После изменений сохраните его
через **Файл → Сохранить файл** или сочетанием клавиш `Ctrl+S`.

Создать новый файл можно через **Файл → Создать**.

## Схемы файлов

Для работы с файлом Junco нужна схема. Она определяет типы полей и свойства,
которые отображаются в редакторе.

Можно попробовать создать схему автоматически: в сообщении об отсутствующей
схеме нажмите **Создать схему**. Проверьте сгенерированную схему и при
необходимости отредактируйте её вручную.

Схема сохраняется рядом с файлом под именем **`имя_файла`.schema.json**.

## Ограничения

Корневым типом файла должен быть объект: это необходимо для хранения метаданных
в поле **`__meta__`**.

## Редактирование схемы

Чтобы переключиться между редактированием файла и схемы, нажмите **Редактировать
схему** вверху основной панели. Редактирование схемы также доступно через меню
**Правка → Схема → Редактировать схему**.

Схема соответствует JSON Schema, но поддерживаются не все возможности стандарта.

## Интерфейс

В приложении три панели:

- **Дерево** — дерево полей для быстрой навигации по файлу.
- **Основная панель** — здесь редактируется содержимое файла или его схема.
- **Панель валидации** — здесь отображаются ошибки проверки.
